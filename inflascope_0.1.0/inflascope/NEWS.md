# inflascope 0.1.0

* CPI data replaced with the official MoSPI download `cpi_1153` (base 2024=100,
  January 2025 to September 2026, 30,030 rows). `get_static_data("cpi")` now
  returns a continuous All India series for the general index and 13 divisions;
  `get_cpi_detail()` and `get_static_data("cpi_detail")` give every state and UT.
* Forecasting minimum lowered from 24 to 18 consecutive months, so the bundled
  21-month series can be forecast and evaluated.
* Dashboard: CPI index chart, division comparison, state comparison, state and
  division filters in the Historical Explorer, and a button that applies the
  latest official food inflation in the calculator.

* R CMD check is now clean (0 errors, 0 warnings, 0 notes).
* Documentation regenerated with roxygen2: every exported function has a valid
  usage section, documented arguments and runnable examples.
* NAMESPACE generated by roxygen2; `utils::tail` declared; unused `jsonlite`
  dependency removed; `tools` declared; `.Rbuildignore` excludes research files.
* New scenario API: `generate_scenarios()`, `get_scenario_data()`,
  `validate_scenario_data()`, `summarise_scenarios()`, with the bundled
  10,000-row synthetic dataset `inst/extdata/inflascope_10000_household_scenarios.csv`.
* Dashboard rebuilt: brand theme, plotly charts on every tab, gap-aware CPI
  lines, a stress test comparing all scenarios over 0-5 years, a forecasting
  readiness panel, and a new Scenario Explorer tab with filters, heatmap,
  summaries and downloads. The HTML report now covers all sections.
* The cache directory is only created when data is imported.
* Test suite expanded from 14 to 88 expectations, including forecasting on a
  continuous synthetic series and a server test of every dashboard output.

* Initial source-attributed snapshot, validation, fixed-basket analysis and Shiny interface.
